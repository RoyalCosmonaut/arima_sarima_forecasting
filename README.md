# Анализ и прогнозирование временных рядов с использованием ARIMA и SARIMAX
 
Репозиторий с моими ноутбуками по прогнозированию среднемесячной температуры воздуха (данные метеостанции №105). Делал в рамках учёбы, разбирался с временными рядами и подбором параметров модели. Где-то код не самый красивый, но работает и результаты адекватные.
 
Данные лежат в `105v2.csv` — там почасовые наблюдения с кучей столбцов (влажность, точка росы, плотность воздуха и т.д.), но для моделей используется только `Tmean`.
 
---
 
## 1. V2_BEST.ipynb
 
Самая вылизанная версия. Тут я перебираю параметры (p,d,q) и сезонные (P,D,Q,12) через `itertools.product`, смотрю AIC и выбираю лучшую комбинацию. В итоге остановился на `SARIMAX(0,1,1)(0,1,1,12)`.
 
Что делается:
- загрузка csv, удаление лишних колонок руками (да, через кучу `del` — знаю что некрасиво, но так было понятнее на тот момент)
- группировка по месяцам, интерполяция пропусков
- декомпозиция ряда (тренд + сезонность + остаток)
- grid search по параметрам SARIMAX
- прогноз на шаг вперёд от 2018-09 и оценка через MSE/RMSE
- прогноз на 30 месяцев вперёд с доверительным интервалом
 
**Результат:** MSE и RMSE получились нормальные, на графиках прогноз ложится довольно близко к факту.
 
## 2. SARIMAX_раб.ipynb
 
Рабочая тетрадка, в которой я экспериментировал. Тут немного другой подход — использую `auto_arima` из `pmdarima` (правда в итоге всё равно руками задал `(1,1,1)(1,1,1,12)`). Импортирован `seaborn`, но по факту графики на `matplotlib`.
 
Отличия от V2_BEST:
- параметры модели другие — `(1,1,1)(1,1,1,12)` вместо `(0,1,1)(0,1,1,12)`
- прогноз стартует с 2019-01-01
- есть динамический прогноз (`dynamic=True`) — можно сравнить как модель ведёт себя без подглядывания в будущие значения
- считается MSE и для обычного, и для динамического прогноза
- прогноз на 500 шагов вперёд (да, многовато, доверительный интервал конечно расползается)
 
**Результат:** Модель с (1,1,1) показывает чуть другую ошибку, интересно сравнить с V2_BEST.
 
## 3. ARIMAv4_впер_2_года.ipynb
 
Версия с прогнозом на ~2 года вперёд. Логика почти как в V2_BEST — тот же grid search, те же параметры `(0,1,1)(0,1,1,12)`. Основное отличие: тут я делаю и статический, и динамический прогноз + считаю MSE для обоих вариантов.
 
Что есть:
- grid search параметров с выводом AIC
- статический прогноз от 2020-01-01
- динамический прогноз от 2019-01-01
- MSE для каждого варианта
- финальный forecast на 30 шагов
 
**Результат:** По сути подтвердил что `(0,1,1)(0,1,1,12)` — оптимальный набор для этих данных.

## Стек
 
- Python 3
- pandas, numpy
- statsmodels (SARIMAX)
- pmdarima (auto_arima, только в SARIMAX_раб)
- matplotlib, seaborn
- sklearn (metrics)
 
## Как запустить
 
1. Положить `105v2.csv` в ту же папку что и ноутбуки
2. Поставить зависимости:
```
pip install pandas numpy statsmodels pmdarima matplotlib seaborn scikit-learn
```
3. Открыть нужный ноутбук в Jupyter и запустить ячейки по порядку
